SERRA DI CASA — come pubblicarla su GitHub Pages

1. Estrai lo zip: trovi la cartella "serra-di-casa".
2. Nel repository GitHub dell'app carica TUTTO il contenuto della cartella
   (index.html, sw.js, manifest.webmanifest, cartella icons), sostituendo i file vecchi.
3. Aspetta 1–2 minuti che GitHub Pages si aggiorni.
4. Sull'iPhone apri l'app: se vedi ancora la versione vecchia, chiudila e riaprila
   (al secondo avvio carica quella nuova).

Prima installazione: apri il link in Safari > Condividi > "Aggiungi alla schermata Home".
I dati (progetti, spesa, diario) restano sul telefono e non si perdono con l'aggiornamento.
