SERRA DI CASA — come pubblicarla su GitHub Pages

Tutti i file sono nella stessa cartella, senza sottocartelle.

1. Estrai lo zip.
2. Nel repository "serra-di-casa" su GitHub: Add file > Upload files, trascina TUTTI
   i file (index.html, sw.js, manifest.webmanifest, version.json, apple-touch-icon.png,
   icon-192.png, icon-512.png) e conferma con "Commit changes".
   I file con lo stesso nome vengono sostituiti. Le tre immagini sono l'icona originale
   dell'app (il terrario nel barattolo).
3. Puoi eliminare dal repository icon-512-maskable.png e, se c'è, la cartella "icons":
   non servono più.
4. Aspetta 1–2 minuti che GitHub Pages si aggiorni.

Aggiornamenti: da questa versione l'app controlla da sola, ogni volta che la apri o ci torni,
se su GitHub c'è una versione nuova (file version.json) e si ricarica da sola.

Icona: l'iPhone non cambia l'icona di un'app già sulla schermata Home. Per vedere quella nuova:
Impostazioni dell'app > "Invia i miei dati" (backup), elimina l'icona dalla Home,
riaprila in Safari > Condividi > "Aggiungi alla schermata Home", poi "Carica dati da file".
